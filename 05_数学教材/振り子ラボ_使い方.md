# 振り子ラボ　使い方

中学校3年「関数 y＝ax²」で使う、ブラウザで動く教材です。振り子の周期 x（秒）と長さ y（m）の関係を、表とグラフで調べます。

- ファイルは `振り子ラボ.html` の1つだけです。インストールもインターネット接続もいりません。
- 生成AI（Claude Code）と一緒に作り、計算と動作は発表者が確かめました。

## 開き方

1. 共有フォルダから `振り子ラボ.html` を**ダウンロード**します（Googleドライブの画面では動きません）。
2. ダウンロードしたファイルを**ダブルクリック**すると、ブラウザ（Chrome・Edge・Safari など）で開きます。
3. パソコン（Windows・Mac）、Chromebook で動作します。スマートフォンでは、ファイルの開き方によって動かないことがあります。

## 使い方（画面の①〜⑤の順に）

| 画面 | すること |
|---|---|
| ① 振り子を動かす | 長さ・ふれはばを動かし、「10往復を計る」を押すと、周期が表に入ります。「手で計るときのずれを入れる」で、実際の測定のようなばらつきが出ます。 |
| ② 実物のデータを入れる | 実物の振り子で測った周期 x と長さ y を入れて「表に追加」。「2021年の授業データを入れる」で、実際の授業で測った10組が入ります。 |
| ③ 表とグラフ | 入れたデータが表と点で表示されます。 |
| ④ どの関数とみなせるかな？ | 関数（比例・一次関数・反比例・y＝ax²）を選び、a を動かして、グラフを点に近づけます。「ずれを確かめる」で、点とグラフのずれの大きさが数値で出ます。ヒント1〜3は、押したときだけ表示されます。 |
| ⑤ 確かめよう | 「ある生成AIは『振り子の長さは周期に比例する』と答えた。本当か」を、表とグラフで確かめます。チャレンジ：1往復にちょうど2秒かかる振り子の長さを求め、「振り子で確かめる」で確認します。 |

## 授業での使い方の例

1. 実物の振り子で周期と長さを測り、②で表に入れる。
2. ④で関数を選び、点に一番合うグラフを探す。比例と y＝ax² の「ずれ」を比べ、根拠をもって「y＝ax² とみなす」。
3. ⑤でAIの答えを検証し、理由を説明する。周期2秒の振り子の長さを予想し、実物で確かめる。

## 数学的な根拠

- 単振り子の周期 T＝2π√(L/g) から L＝(g/4π²)T²、g/4π²≒0.248（g＝9.8 m/s²）。周期2秒で長さは約0.99 m。
- ふれはばが大きいと周期は少し長くなります（30°で約1.7％）。教材では、ふれはばによる補正も計算しています。
- 2021年の授業データ（10組）では、点とグラフのずれは y＝0.25x² で 0.025 m、比例（最も合う a≒0.39）で 0.108 m でした。
