# オンライン副担任

小学校・中学校（通常の学級／特別支援学級／特別支援学校／通級）の先生の授業づくりを支える、学習指導案の作成アプリです。
先生の意図を立てるNo.2として、そのまま使える指導案を書き、最後に「副担任からの進言」（つまずきへの手立て、判断が必要な点、改善提案）を添えます。

## できること

| 指導案の種類 | 用途 |
| --- | --- |
| 板書型指導案 | 板書計画を中心に1時間を1枚で見渡す。日々の授業準備に |
| 日々の学習指導案（略案） | 毎日の本時案。展開・発問・評価を短く |
| 研究授業の学習指導案（細案） | 単元の目標・評価規準・児童生徒観／教材観／指導観・指導と評価の計画・本時案・板書計画・研究協議の視点 |

- 対象：小学校1〜6年・中学校1〜3年の全教科（道徳・総合・特別活動を含む）
- **算数・数学は専門ナレッジ**（学年別の内容、問題解決型授業の流れ、板書の原則、領域別の典型的なつまずき）を持たせています
- **特別支援**：特別支援学級・学校・通級、障害種別の支援例、自立活動6区分27項目、知的障害の各教科の段階

## 使い方（先生のパソコンで）

必要なもの：Node.js 22 以上、Anthropic の APIキー（https://console.anthropic.com で取得）

```bash
npm install
npm start
```

ブラウザで http://localhost:3939 を開き、右上の「設定」で APIキーを登録します。
APIキーはこのパソコンのホームフォルダ（`~/.online-fukutannin/config.json`）にだけ保存され、外部には APIの呼び出し以外で送られません。

## 個人情報について

- 児童生徒の実名・住所・病名など、個人が特定できる情報は入力しないでください（仮名「Aさん」などで）
- 入力内容は指導案の生成のために Anthropic の API に送信されます。所属自治体の生成AI利用ガイドラインも確認してください
- 生成された指導案は下書きです。数値・学習指導要領の文言・教科書との対応は、必ず先生が確認してください

## 開発者向け

```bash
npm test      # テスト（APIは呼ばない）
npm run lint  # 型チェック
npm run dev   # 変更を監視して再起動
```

構成：

```
src/core/persona.ts            副担任の人格（システムプロンプト）
src/core/knowledge/subjects.ts 全教科の見方・考え方・内容構成
src/core/knowledge/math.ts     算数・数学の専門ナレッジ
src/core/knowledge/specialNeeds.ts 特別支援教育ナレッジ
src/core/templates.ts          3種類の指導案の構成
src/core/promptBuilder.ts      入力の検証とプロンプトの組み立て
src/core/generator.ts          Claude API 呼び出し（ストリーミング）
src/server.ts                  ローカルサーバー（127.0.0.1 のみ）
public/                        画面
```

今後の計画は [docs/roadmap.md](docs/roadmap.md) を参照してください。
