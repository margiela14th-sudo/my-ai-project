description: 現在の変更を Codex にレビューさせ、妥当な指摘だけ反映する
argument-hint: "[レビューで特に見てほしい点（任意）]"
---

現在の変更を Codex にレビューしてもらいます。

1. `git diff HEAD` で変更内容を確認する（変更がなければそう伝えて終了）。
2. Codex に、その diff のレビューを依頼する。
   - MCP ツール `codex` が使えればそれを使う。
   - 使えなければ Bash で `codex exec "<依頼文>"` を実行する。
   - 依頼文には diff と、AGENTS.md のルールに従うことを含める。
   - 追加の観点: $ARGUMENTS
3. 返ってきた指摘を「妥当 / 不要 / 要確認」に分類して一覧にする。
4. 「妥当」のものだけ修正し、テストがあれば実行する。
5. 最後に、反映した指摘と見送った指摘（理由つき）をまとめる。
