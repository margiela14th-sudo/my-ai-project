# 板書型指導案を作る

板書型指導案＝黒板の図が中心の指導案。1枚（A4横）で授業の流れが分かるようにする。
出力：`板書型指導案.png`（印刷・配布用）、`板書型指導案.pdf`（A4横1枚）、`板書型指導案.html`（修正用）、`板書のみ.png`（文字の指導案に貼る用）。

## 守ること（研究上の約束）

- 生徒の反応・発言は「予想」として書く。実際の授業記録と混ぜない。生徒の氏名は書かない。
- 実測データ・統計を板書に載せたら、`footnote` に出典（どの授業の記録か、どの資料の何年・何ページか）を書く。
- 写真に生徒の顔が写っていたら使わない。
- 過去の板書計画は上書きしない。

## この先生の板書の型（2021年 振り子の板書計画より）

- 左から右へ授業が進む。左上に日付、続いて導入の問い（「これは何？」）。
- **「課題」「問題」は枠で囲む**。課題（単元を貫く問い）→ 問題（本時で数学的に扱う形）の順。
- 生徒の予想は「・」の箇条書きで残す。気づき・結論は **◎** を付ける。
- 大事な気づきは**黄色の付箋（赤字）**で貼る（`sticky`）。教材の写真やICT画面は磁石で貼る（`image`）。
- 表 → グラフ → 「〜とみなす」の順で、数学化の過程が見えるようにする。最後に「まとめ」を枠で。
- チョークの色：白＝基本、黄＝強調・課題、ピンク＝まとめ・結論、青＝補足・条件。

## 手順

1. **聞き取る**（足りない分だけ）：学年・単元・本時のねらい・課題・主な発問・使う教材。元の板書計画や写真があれば先に見る。
2. **JSON を書く**：`examples/sample_bansho.json` を写して書き換える（完成見本は `examples/sample_板書型指導案.png`）。
   - 上の枠：`title`、`unit`、`goal`、`eval`
   - `columns`：黒板を縦に区切った列（3〜4列が見やすい）。`width` は幅の比。
     - `items`：黒板に書くもの（上から順）
       - `date`／`text`（`color`: white・yellow・pink・blue、`big`、`bold`）
       - `box`（`label`: 課題・問題・まとめ、`color`）
       - `list`（箇条書き）／`formula`（式。`^2` は ² になる）／`arrow`
       - `table`（`rows`、`headerCol`）／`graph`（`points`、`curve`: "0.25*x*x" のような x の式、`xmax`、`ymax`）
       - `sticky`（黄色の付箋）／`card`（生徒の考えを書いたホワイトボード）／`image`（`src` は JSON からの相対パス、`caption`）／`note`（小さい字）
       - 文字の中の `**ここ**` は黄色になる。`\n` で改行。
     - `stage`（「導入（7分）」など）、`hatsumon`（主な発問）、`hannou`（予想される反応）、`ryuiten`（留意点・◆評価・☆ICT）
   - `boardHeight`（黒板の高さ px、既定600）、`footnote`（出典など）
3. **作る**：
   ```bash
   node .claude/skills/bansho-shidoan/scripts/render_bansho.js 板書.json 出力フォルダ
   ```
   Playwright と Chromium が必要（このクラウド環境には入っている。自分のPCでは `npm install playwright` と `npx playwright install chromium`）。
4. **見て確かめる**：`板書型指導案.png` を開いて、文字のはみ出し・重なり・列の詰まりを確認する。詰まっていたら、文を短くする → 列の `width` を調整 → `boardHeight` を増やす、の順で直す。黒板は「実際に書ける量」が目安（1列に5〜7項目）。
5. **渡す**：PNG と PDF を渡す。文字の指導案も作るなら、`板書のみ.png` を shidoan の `boardImage` に指定する。
