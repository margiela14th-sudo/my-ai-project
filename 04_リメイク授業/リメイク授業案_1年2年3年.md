# リメイク授業案（提案・未実践）

## 中学校3年　関数y＝ax²「振り子の長さと周期」（重点事例）
- **本時の目標**：振り子の周期と長さの関係を実測データから y＝ax² とみなし、根拠を説明するとともに、式を使って周期2秒の振り子の長さを求めることができる。
- **中心発問**：振り子のひもの長さと1往復にかかる時間には、どのような関係があるだろうか。

| 段階 | 学習活動 | 教師の手立て・AI活用 |
|---|---|---|
| 導入（7分） | 巨大ブランコの動画。「何m の高さから吊されている？」「何がわかれば求められる？」 | 生徒の予想をひろう（残す） |
| 実験（12分） | 長さ10〜40cmの振り子で10往復を計り、周期を求めて表にする | 実物の体験（残す）。平均の取り方は生徒と決める |
| 自力解決（10分） | 振り子ラボに入力し、点を見て関数を予想・選ぶ | ヒント1〜3を段階的に（正解は出さない） |
| 練り上げ（10分） | 比例・一次関数・反比例・y＝ax²のずれを比べ、y÷x² がほぼ一定であることから y＝ax² とみなす | 「AIは長さは周期に比例すると答えた。正しい？」と検証させる |
| まとめ（6分） | y＝0.25x² に x＝2 を代入 → 1m。シミュレーションと実物で確かめる | 振れ幅が大きいと合わなくなる（成立条件）にふれる |
| 振り返り（5分） | わかったこと／ICTが役立った場面とその理由 | 2021年の課題に応える項目。振り返り自動化で集計 |

## 中学校2年　一次関数「ソメイヨシノの開花日」
- **本時の目標**：2月の平均気温と開花日の関係を一次関数とみなし、開花日を予想することができる。
- **中心発問**：さくらの開花には何が影響しているのか。
- **展開**：①年と開花日、年と気温のグラフから気づくこと ②気温と開花日の散布図に自分で直線を引き、2点から式を求める ③今年の気温から開花日を予想 ④「AIは1℃上がると10日早くなると答えた」をデータで検証（資料のデータでは約3日）⑤予想と実際を比べる（春に確認）
- **AI活用**：データの最新年までの整形（教師が気象庁の原典と照合）、散布図教材の作成、誤答例の作成
- **注意**：相関係数・回帰は扱わない

## 中学校1年　比例「地震」（構想）
- **本時の目標（案）**：初期微動継続時間と震源からの距離の関係を比例とみなし、距離を求めることができる。
- **展開（案）**：観測点ごとの初期微動継続時間と距離の表 → グラフ → 比例定数の意味（1秒あたり何km）→ 自分の地点の距離を求める
- **AI活用（案）**：観測データの整理、比例を確かめる動的教材の作成
- **注意**：比例定数は地域・深さで変わる近似（大森公式）。理科と扱いを合わせる。過去の授業資料を確認してから確定する。
