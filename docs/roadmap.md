# ロードマップ

## 第1段階（いまここ）：指導案生成の土台
- [x] 3種類の指導案（板書型・略案・研究授業細案）
- [x] 全教科の基本ナレッジ、算数・数学の専門ナレッジ、特別支援ナレッジ
- [x] ローカルで動く画面、APIキーの端末内保存
- [ ] 実際の授業で使って、先生（開発者本人）が品質を評価する

## 第2段階：品質を「研究授業レベル」に上げる
- [ ] 評価セット：単元×学年×指導案種別の代表ケース（20〜30件）を作り、良い指導案の基準（目標と評価の一貫性、時間配分、発問の具体性、計算の正しさ等）で採点する
- [ ] 算数・数学：単元ごとの「既習→本時→発展」の系統表、典型的な誤答の事例を増やす
- [ ] 学習指導要領・解説の本文を検索して引ける仕組み（文言の正確さのため）
- [ ] 先生自身の過去の良い指導案を「お手本」として読み込める機能
- [ ] 生成後の対話での修正（「導入をもっと短く」「Bさんへの支援を追加」など）

## 第3段階：配布・販売に向けて
- [ ] Word（.docx）・PDF での書き出し（学校の様式に近い体裁）
- [ ] デスクトップアプリ化（Windows / Mac のインストーラ。Electron などで現在のコードを包む）
- [ ] 料金モデルの決定：
  - 買った先生が自分の APIキーを使う方式（現在の作り。運営費がかからない）
  - 月額制で運営側がAPI費用を負担する方式（先生にとって簡単だが、サーバーと課金の仕組みが必要）
- [ ] 利用規約・個人情報の扱いの明記、自治体の生成AIガイドラインとの対応表
- [ ] ライセンスキーによる購入者認証
