## 3．AIの役割分担

| AI | 役割 | 連携方法 |

| Claude Code | 全体設計、分析、構成、原稿、PPT/Word/PDF生成、HTML教材の初版、統計調査、整合管理 | このリポジトリで直接作業 |
| Codex | HTML教材のコードレビューと数値テスト、統計数値の二重チェック、PPT/Wordの整合チェック、セカンドオピニオン | **現在このクラウド環境では Codex MCP が起動できない（codex コマンドが無い）**。当面は先生が Codex に貼り付ける依頼プロンプトを HANDOFF.md に用意する |
| ChatGPT | 聴衆（一般の数学教員）目線での分かりやすさ評価、想定質問の洗い出し、文体の自然さの確認 | 先生が貼り付けるプロンプトを用意 |

ルール
- 同じファイルを複数のAIが同時に編集しない（HANDOFF.md の「編集中」欄で管理）。
- Codex・ChatGPT の指摘は根拠を確認してから反映する。
- 生徒の氏名・成績・振り返りは、外部AIに送る前に匿名化する。
