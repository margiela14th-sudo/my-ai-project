## 2．研究発表の様式・章立て

### 2-1 3本に共通する章立て

```
研究のねらい（生徒の現状 → 原因 → 手立ての発想）
研究仮説（2022のみ明示）
研究の内容と方法（①〜③の手順）
授業の実際（場面ごと：①きっかけ ②解決 ③共有 ④振り返り）
成果○と課題●（▲）
今後の展望
参考・引用文献
ご清聴ありがとうございました。
```

### 2-2 各資料の構成

| 2021 日数教（PDF） | 2022 全数（PDF） | 2023 第二地区（PPT, 18枚） |
|---|---|---|
| 表紙（題・副題・所属氏名・共同研究者） | 表紙 | 表紙 |
| 研究のねらい | 研究のねらい（生徒の現状・原因・評価の観点） | はじめに（きっかけ：ハンドブック紹介／若手支援） |
| 研究の内容と方法①〜③ | 研究仮説 | はじめに（県調査 正答率22.2%） |
| 授業の実際①学習のきっかけ（ハイジのブランコ） | **この研究でわかったこと（成果を先出し）** | 授業構成の視点（2場面） |
| 授業の実際②解決（関数を取り出す：比例／一次／反比例／y=ax²） | 研究の内容と方法（1）〜（3） | **成果○と課題▲（先出し）** |
| 授業の実際③共有（周期2秒の振り子） | 実践した手法の説明 | 単元計画（表） |
| まとめ（○成果／●課題） | 単元計画（表） | 授業の実際（導入／解決） |
| 板書 | 授業：本時の主眼・課題・授業の流れ（4段の表） | 生徒のふりかえり（画像×4） |
| ご清聴 | T/S の授業記録（逐語） | 成果○と課題▲（再掲） |
| | 成果○と課題●、今後の展望、参考・引用文献、ご清聴 | ご清聴 |

### 2-3 様式上の特徴

- **成果の先出し**（2022・2023）：結論を早めに示してから実際を説明する。
  → 今回は実測の成果がまだ無いため「成果」は先出しできない。代わりに「本研究の提案（AI LESSON REMAKE）」を先出しする構成を提案。
- **成果は○、課題は●または▲**の記号で箇条書き。
- **「本時の主眼」「課題」「授業の流れ」**の3点セットで授業を示す（2022）。
- **T（教師）／S（生徒）の発言記録**で授業の実際を再現（2022・2023ノート）。
- **単元計画を表で示し、本時の位置**を明示（2022・2023）。
- **板書写真・生徒のふりかえり画像**を根拠として示す（2021・2023）。
- 全スライドのフッターに「大会名 発表資料」「演題」「日付」「ページ番号」（2023 PPT）。
- 全スライドに**発表者ノート（話し言葉の原稿）**あり（2023 PPT）。

## 3．文章表現と文体

| 項目 | 特徴 | 例 |
|---|---|---|
| 発表原稿（ノート） | です・ます調、話し言葉、聴衆への語りかけ | 「みなさんなりに自分だったらこうするといったアレンジを加えていってほしいです。」 |
| スライド本文 | 体言止め・短文・矢印（→、⇒、▶） | 「→何がわかると調べられそうですか？」 |
| 研究のねらい | 現状→原因→「〜ではないかと考えた」 | 「内容理解のための有効な手立てがたてられていないのではないか？」 |
| 研究仮説（2022） | 「〜を行うことで、〜することができる。」 | 「ジグソー法を用いた授業を行うことで、生徒の粘り強い取組を行おうとしている側面や、自ら学習を調整しようとする側面を引き出すことができる。」 |
| Word原稿（2021） | である調、**句読点は「，」「．」** | 「…ICT機器を効果的に活用・導入できるのではないかと考えた．」 |
| 成果・課題 | 「〜できた」「〜が必要である」「〜の余地がある」 | 「●授業の中心発問やICT機器を扱うタイミングは検討の余地がある．」 |

**研究仮説の文体調整案**（ご指定の仮説を過去の書き方に合わせたもの。決定は確認事項）：

- 案A（ご指定のまま・推量形）
  従来の数学科授業実践における数学的な価値や教師の指導意図を継承しながら、生成AIを活用して授業を再構築することで、教師の授業準備に関わる負担を軽減するとともに、生徒の数学的な見方・考え方を働かせる授業の実現につながるのではないか。
- 案B（2022年の仮説の型「〜ことで、〜できる。」に合わせたもの）
  従来の数学科授業実践における数学的な価値や教師の指導意図を継承しながら、生成AIを活用して授業を再構築することで、教師の授業準備に関わる負担を軽減するとともに、生徒が数学的な見方・考え方を働かせる授業を実現することができる。

## 4．図表・数式の活用

- 表：単元計画、授業の流れ（4段）、実測データ（x秒／ym）。
- グラフ：実測値の散布 → GeoGebraで候補関数を重ねて比較（2021）。
- 数式：y＝0.25x²、y＝1/4x² の表記揺れあり（今回は統一が必要）。
- 画像：板書写真、生徒の振り返り、題材写真（ハイジのブランコ、巨大ブランコ）。
  → 題材写真（アニメ画像等）は著作権の確認が必要。

## 5．授業観・教育観（資料から読み取れるもの）

- **生徒の予想・発言から授業をつくる**（全員伏せて挙手、ペアで確認、「なんで？」ととぼけて問い返す）。
- **低位の生徒の発言を意図的にひろい、授業の見通しをつくる**（2022）。→ ご指定の「苦手な生徒を取り残さない」と一致。
- **どの生徒にも学びがある場面設計**（単位変換・3桁化・基準の変更という層別のつまずきを想定）。
- **現実の事象を数学化する**（ジョギング、碁石、ブランコ、振り子、桜）。
- **「みなす」ことを重視**（2乗に比例する関数とみなす、比例とみなす問題を今後の展望に記載）。
- **実物と ICT の両方の良さ**を認める（「実物の振り子を使う良さもある」）。
- **教師の授業力を他の教員へ広げたい**（「鉄板ネタ」「ハンドブックを身近に」「アレンジを加えてほしい」）。
  → 今回の「他の教員も使える再現性のあるモデル」という提案と強く結びつく。

## 6．継承する様式

1. 章立て：研究のねらい → 研究仮説 → 研究の内容と方法 → 授業の実際 → 成果○と課題● → 今後の展望 → 参考・引用文献 → ご清聴
2. 成果○・課題●の記号表記
3. 「本時の主眼」「課題」「授業の流れ」の3点セット
4. 単元計画表と本時の位置
5. 全スライドのフッター（大会名・演題・日付・ページ番号）と発表者ノート
6. 授業記録（T/S）による授業の再現
7. Word原稿：番号見出し「１．」、である調、「，．」句読点（大会要項で要確認）

## 7．改善する点

| 過去資料 | 改善案 | 理由 |
|---|---|---|
| 文字量の多いスライド（2023成果課題スライド等） | 1スライド1メッセージ、詳細はノートと補足へ | 15分で14枚、1枚約1分 |

| 題材写真の出典なし | 出典・使用許諾を明記 | 県大会での公開 |
