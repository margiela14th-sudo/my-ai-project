# 授業リメイク用プロンプト（AI LESSON REMAKE）

他の数学の先生が、自分の授業を生成AIでリメイクするためのプロンプトです。STEPごとに順に使います。
**注意：生徒の氏名・成績・個人が特定できる振り返りは入力しないでください。AIの出力は必ず教師が確かめてください。**

---

## STEP1〜3　過去の授業を整理する
```
あなたは中学校数学の授業研究に詳しい指導主事です。
以下は私が過去に行った授業の資料です（学年・単元・ワークシート・板書・振り返りの要約・当時の課題）。

【学年・単元】
【本時の目標】
【中心発問】
【授業の流れ】
【当時の課題（研究発表や反省で書いたもの）】

次の形式で整理してください。
1. この授業の数学的な価値（何を「みなす」「予測する」「説明する」授業か）
2. 良かった点を三つ（根拠となる資料の箇所も）
3. 課題を三つ（特に、つまずく生徒への支援と、準備にかかる手間の観点で）
資料に書かれていないことは推測せず「資料に記載なし」としてください。
```

## STEP4　改善案を出させる
```
STEP1〜3の整理をもとに、改善案を三つ出してください。条件：
- 授業の本質（数学的な価値・中心発問・生徒が考える時間）は変えない
- 未習事項を使わない（学習指導要領と教科書の範囲内）
- 次のいずれかを含む：動的教材（条件を変えられる、式・表・グラフが連動）、段階的ヒント、誤答例の比較、AIの回答を検証する活動
- 正解をすぐに表示しない
- 各案について「教師の準備時間が減る点」「基礎の理解を支える点」「注意点」を書く
```

## STEP5　教師が吟味する（チェックリスト）
- [ ] 数学的に正しいか（式・数値・成立条件を自分で確かめた）
- [ ] 未習事項を使っていないか
- [ ] 苦手な生徒が取り残されないか（ヒントの段階）
- [ ] 生成AIを使わない方がよい場面はないか（実物体験・考える時間）
- [ ] 生徒の個人情報を入力していないか

## STEP6　残す・変える・削るで再構築
```
次の判断で授業を再構築し、板書型指導案（本時の目標、導入、中心発問、予想される生徒の反応、展開、まとめ、板書）にしてください。
残す：
変える：
削る：
```

## 動的教材をつくる（HTML）
```
中学校数学の授業で使う、単一HTMLファイルの教材を作ってください。
- 題材：
- 生徒が変えられる条件：
- 式・表・グラフを連動させる
- 正解はすぐ表示せず、ヒントを3段階で出す
- 外部ライブラリ・通信なし、タブレット（幅768px）でも使える
- 数式と計算の根拠をコメントで示す
```

## STEP7　検証の記録
- 改善前／改善後の時間（授業準備・教材作成・指導案・板書計画・AI出力の確認修正）
- 時間削減率（％）＝（改善前の時間 − 改善後の時間）÷ 改善前の時間 × 100
- 生徒：基礎の到達率、数学的な説明、振り返りの内容
