# 中学1年生 スタートガイド｜中学校生活オリエンテーション

入学直後の学年集会・学級活動で使う、**全20枚・16:9** のオリエンテーションスライドです。
PowerPoint で開くとそのまま編集できます。説明時間の目安は **約25〜28分**（短くする場合は後述）。

## まず最初に編集するところ（5分でできます）

学校ごとに異なる情報は、**黄色い点線のボックス【〜を入力】** になっています。
ボックス内の文字を選択して書き換えてください（ボックスごと消しても構いません）。

| 優先 | スライド | 編集する欄 |
| --- | --- | --- |
| ★ | 01 表紙 | 【学校名を入力】【年度を入力】 |
| ★ | 18 相談 | 【学校の相談窓口・連絡方法を入力】、スクールカウンセラーの来校日【入力】、【地域の相談窓口を入力】 |
| ★ | 07 中学校の1日 | 7つの【時刻】（学校の時程表に合わせる。項目名「昼食」なども書き換え可） |
| ★ | 08 学校生活のルール | 時間・服装・持ち物・施設の使い方の【ルールを入力】×4 |
| | 04 授業 | 【授業時間を入力】分 |
| | 05 定期テスト | 【テストの回数・時期を入力】 |
| | 09 持ち物 | 【学校で必要な持ち物を入力】 |
| | 11 部活動 | 【運動部の名前を入力】【文化部の名前を入力】【地域クラブ名を入力】 |
| | 12 学校行事 | 行事名（校外学習・体育祭・文化祭は文字を直接変更可）、【行事名を入力】、【時期を入力】×4 |
| | 13 生徒会・委員会 | 【委員会を入力】 |
| | 19 3年後の自分 | 考える時間・話す時間の【　】分 |

> PowerPoint の［ホーム］→［選択］→［オブジェクトの選択と表示］を開くと、編集欄は **「編集_〜」** という名前で一覧表示されます。

### 編集できるもの

- **すべての日本語**：PowerPoint 標準のテキストボックスです（イラストの中に文字は入っていません）
- **カード・矢印・丸・チェック欄などの図形**：色・大きさ・位置を自由に変更できます
- **イラスト**：画像として埋め込み済み（外部リンクなし）。移動・拡大縮小・削除できます
- **配色・フォント**：テーマに設定済み（［デザイン］→［バリエーション］から変更可）

## 構成（全20枚・6章）

章ごとにアクセントカラーが変わり、右上の6つの丸で「いま何章か」が分かります（冒険の道しるべ）。

| 章 | 色 | スライド | 時間目安 |
| --- | --- | --- | --- |
| 第1章 ようこそ中学校へ | イエロー | 01 表紙 / 02 3年間の成長ロードマップ | 2.5分 |
| 第2章 小学校と中学校の違い | ブルー | 03 先生が変わる？ / 04 授業はどう変わる？ / 05 定期テストって何？ / 06 家庭学習のポイント | 5.5分 |
| 第3章 中学校生活の基本 | グリーン | 07 中学校の1日 / 08 学校生活のルール / 09 持ち物と提出物 / 10 スマホ・SNSとの付き合い方 | 6分 |
| 第4章 中学校の楽しみ | オレンジ | 11 部活動・地域クラブ活動 / 12 学校行事 / 13 生徒会・委員会活動 / 14 学級活動 | 4分 |
| 第5章 人との関わりと成長 | パープル | 15 友達との関わり方 / 16 自分で考えて行動する / 17 失敗は成長のチャンス | 4.5分 |
| 第6章 安心と未来 | ティール | 18 困ったときは相談しよう / 19 3年後の自分を想像しよう / 20 中学校生活、スタート！ | 6.5分 |

**生徒が考える・話す場面**：03（となりと15秒）、07・12（問い）、08（理由を30秒で話す）、16（30秒）、19（ワーク約4分）

**20分に短くしたい場合**：06・09・14 を学級活動の別時間に回す／19 のワークを宿題にする、など。

## 発表者ノート（教員向け授業設計）

全20枚に、次の5項目を記載しています（［表示］→［ノート］で確認）。

1. このスライドで伝えたいこと
2. 教師の説明例（そのまま読める話し言葉）
3. 生徒への問いかけ
4. 編集が必要な項目
5. 想定所要時間

18枚目のノートには参考として「24時間子供SOSダイヤル」の番号を記載しています。**掲載前に最新情報を確認してください。**

## 使用上の配慮

- 学校ごとに異なるルール・行事・時程は断定せず、すべて編集欄にしています。
- 15枚目は「全員と同じように仲良くしなくても大丈夫」、18枚目は「学校に行きづらいときも相談していい」と明記しています。生徒の状況に応じて言葉を調整してください。

## フォントと表示環境

- 指定フォント：**メイリオ（Meiryo）**。Windows の PowerPoint ではそのまま表示されます。
- Mac / iPad の PowerPoint・Keynote、Google スライドでは、メイリオがない場合に自動で別の日本語ゴシック体（ヒラギノ角ゴ等）に置き換わります。行間は固定値で指定しているため大きく崩れにくい設計ですが、文字幅がわずかに変わることがあります。
- PDF は Noto Sans CJK JP で作成・埋め込み済みのため、どの端末でも同じ見た目です。

### 未検証の事項

- **Microsoft PowerPoint / Keynote / Google スライド実機での表示は未確認**です（制作環境が Linux のため）。確認は LibreOffice によるレンダリングで行いました。
- メイリオ自体での表示は未確認です（確認時はメトリクスの近い Noto Sans CJK JP で代替）。全角文字の幅は同等ですが、英数字や行の高さにわずかな差が出る可能性があります。
- iPhone 実機での PDF 表示は未確認です（フォント埋め込み・ページサイズ 16:9 は確認済み）。

## 作り直す場合（ソースコード）

`../orientation/` に生成用コードがあります（Python 3 + python-pptx / CairoSVG / Pillow、LibreOffice・Poppler）。

```bash
cd orientation
python3 build_pptx.py   # PPTX を生成（文章は build_pptx.py、ノートは notes.py）
python3 verify.py       # 検証・PDF・一覧画像を生成
```

- `illustrations.py`：オリジナルイラスト（SVG）の生成
- `assets/icons/`：アイコン SVG（`tools/render_icons.js` で書き出し）
